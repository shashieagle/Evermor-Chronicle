# PROJECT CONTEXT

Design and develop the "Begin Your Story" page for the Evermor website.

Evermor is an editorial storytelling studio that preserves the beginning of a family's story.

The Homepage, Beginnings page, Individual Beginning pages and About page are already completed.

This page is NOT a contact page.

It is the first conversation between Evermor and a couple.

The experience should feel warm, calm, personal and deeply intentional.

Visitors should leave feeling understood rather than processed.

Reuse the existing design system completely.

DO NOT redesign the website.

Reuse:

• Navigation
• Typography
• Colours
• Background
• Grid
• Spacing
• Components
• Motion
• Footer

The page must feel like the final chapter before a conversation begins.

------------------------------------------------------------

# PAGE STRUCTURE

The page contains only four movements.

1. Hero

2. Gentle Introduction

3. The Conversation

4. Quiet Closing

Nothing else.

No testimonials.

No FAQ.

No pricing.

No cards.

No decorative graphics.

No icons.

No illustrations.

------------------------------------------------------------

# DESIGN LANGUAGE

The entire page should feel calm.

Minimal.

Editorial.

Quiet.

Human.

Whitespace is a design element.

Avoid visual noise.

Do not introduce:

• Cards

• Shadows

• Borders around sections

• Large coloured backgrounds

• Decorative shapes

• Icons

• Illustrations

Everything should feel effortless.

------------------------------------------------------------

# FORM DESIGN

Inputs should almost disappear.

Use either:

• thin underline

OR

• extremely subtle border

Rounded corners should be minimal.

Labels remain visible.

Focused input:

• underline darkens slightly

• label shifts subtly

No dramatic animations.

Textareas automatically expand while typing.

------------------------------------------------------------

# TYPOGRAPHY

Maintain the existing Evermor typography system.

Editorial rhythm.

Generous line-height.

Large whitespace between paragraphs.

Never allow long walls of text.

------------------------------------------------------------

# RESPONSIVENESS

Desktop:

Single elegant reading column.

Tablet:

Maintain generous margins.

Mobile:

Preserve whitespace.

Do not compress vertical rhythm.

The page should still feel slow and intentional.

------------------------------------------------------------

# ACCESSIBILITY

Semantic HTML.

Accessible labels.

Keyboard navigation.

Visible focus states.

ARIA where appropriate.

------------------------------------------------------------

# PERFORMANCE

Reuse existing components.

Reuse typography tokens.

Reuse spacing utilities.

Reuse animations.

Do not introduce additional libraries.

------------------------------------------------------------

# MOTION

Reuse the site's animation system.

Fade-up transitions only.

Duration:
600–800ms.

No parallax.

No cinematic effects.

No excessive scrolling animations.

------------------------------------------------------------

# FINAL EXPERIENCE

When someone finishes this page, they should not feel like they submitted an enquiry.

They should feel like they have written the first page of their family's story.

The entire experience should feel deeply personal, elegant and timeless.

Return clean, production-ready code that integrates seamlessly into the existing Evermor website.
